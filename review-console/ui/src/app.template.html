Project default for architectural review (Review & Plan tab) — applies to all users. Can be overridden per call from the ingestion drawer's Review & Plan tab.

Enhancement model
Project default for enhancement-plan generation (Review & Plan tab). Falls back to the Arch Review model when unset. Can be overridden per call.
Stored server-side. Leave unset to share the Arch Review default.
