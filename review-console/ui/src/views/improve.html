Calibration — fixture battery vs reference
Every row is one scored run of the ground-truth fixture suite (12 UCs, 9 seeded gaps, 5 controls), all scored by the same scorer. Reference rows are the ceiling — a frontier model (or human adjudication) on the identical blind pack. Nightly rows track the production model over time. The gap between them is the number a new prompt, method, or model has to close: a change is an improvement only if its row moves toward the reference without giving back precision.
