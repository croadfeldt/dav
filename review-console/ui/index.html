Evaluation model
Project default for new analysis runs — applies to all users. Can be overridden per run in the New Run modal.
Stored server-side. Only registered model endpoints can be set as the project default.
UC Authoring model
Project default for LLM-assisted use case authoring — the Assist panel, the UC Wizard, and Bulk import all use it. Can be overridden per use.
Stored server-side. Only registered model endpoints can be set as the project default.
Arch Review model
Project default for architectural review (Review & Plan tab) — applies to all users. Can be overridden per call from the run drawer's Review & Plan tab.
Stored server-side. Only registered model endpoints with use_arch_review = true are eligible.
Enhancement model
Project default for enhancement-plan generation (Review & Plan tab). Falls back to the Arch Review model when unset. Can be overridden per call.
Stored server-side. Leave unset to share the Arch Review default.
